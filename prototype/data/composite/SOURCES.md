## 引用长度

- 每条输入的正文截到 500 字符（含省略号），原长写在 `text_length`；3196 条里 973 条被截断（家庭流的消息都短，没有被截断的）。标题截到 160 字符。
- 事项来源里的引文（`sources[].quote`）截到 280 字符，它们是 Agent 从同一批正文里摘的原句。
- 输入的链接保留，但域名、仓库名、账号、帖子与评论编号都已化名，大多打不开，也不能直接指回原帖。

## 化名处理

规则以 [MIX.md 的改写规则](../../../corpus/composite/MIX.md#改写规则)为准，这里只列演示读者会碰到的几项：

- 人物 Jonas Berglund、项目 skarv、公司 Lindbo、论坛 Wildlog Forum 以及全部账号与人名都是化名；同一个真实名字在所有流里换成同一个化名。家庭流里的家人、朋友、邻居、诊所与水管工是作者起的名字，查过不与其他流的化名重名。
- 化名不是匿名：正文是真实原文，逐字搜索仍可能找回出处。
- 演示用 v1.1 加家庭流的正文、署名与链接，与第二次自由运行看到的是同一版；第一次自由运行看到的是 v1，那次的版本差别记在[第一次自由运行的报告](../../../docs/evaluations/free-run-composite-2026-10-15.md)。

## 公开之前

站点构建（`npm run site:build`）会把 `prototype/data/` 下的 `.mjs` 一起发布。2026-10-15 用户决定照现状公开，站点已发布到 fold.vibecoding.icu。已知缺口与退路：

1. life 流来自 Stack Exchange，许可是 CC BY-SA，要求署名并链接原帖；化名改写后无法逐条满足，这里只能笼统声明来源与许可。family 流是原创文本，没有许可问题。
2. 若收到来源方异议，把 [select.mjs](../select.mjs) 的默认数据集切回 `story`，在站点构建中排除 `data/composite/`，重新 `npm run deploy`。
