# A 空间排布 · 动画记录

状态：2026-10-20，按第三轮的六步流程（reference → data → story → motion → direct → ship）重做 [A 空间排布](../../index.html?variant=a&frame=23)。第 1–4 节（参考、数据、故事、交互）在任何东西动起来之前写下，代码照它做；第 5–7 节是实现、与故事的出入和交付。原型探索，不是规范。A 现在怎样工作、承载哪类回应见 [spatial.md](spatial.md#a-空间排布)；两层法则与交互标准见 [CONCEPTS.md](../CONCEPTS.md#第三轮概念动画)；阅读加作答的范本是 D（[home-motion.md](home-motion.md)：答一件少一件、回执跟着条目走）与腕上一瞥（[watch-motion.md](watch-motion.md)：换轮三拍、自动讲一遍）。数字都由 `scenario.mjs` 回放现算，规则见 2.1；推算脚本只留在本机，不入库。

A 和 D 一样是阅读加作答的工具，场景是“桌前，生活急事要当场二选一”。和 D 不同的是 A 有一张桌面：纸片的位置是先后（越急越靠左上），面积是份额，空着的桌面是留白。所以 A 的动画要回答的不只是“答了之后少了一件”，还有“它让出的面积去了哪、谁挪到了哪里”。

### 1.1 A 现在怎么变

读 [a.mjs](../../variants/a.mjs)、[a.css](../../variants/a.css) 与 [spatial-kit.mjs](../../variants/spatial-kit.mjs) 所见：

| 时刻 | 现在怎么动 | 断在哪 |
| --- | --- | --- |
| 换轮（←/→、时间轴、空格每 5.6 秒） | 纸片用 `createFlipBoard`：留下的平移缩放 320 ms，新纸片从 60% 大小处晚 58 ms 淡入，撤下的原地收缩，并入的飞进目标；左栏 `flipList` 280 ms，离开的卡 112 ms 淡出，新卡随后进来；标题、日期、本轮调用一行与份额读数硬切 | 一切挤在 0–0.32 秒里一起动，没有先后。位置跨帧不稳：composite 27 次换轮里纸片共挪了 224 次，其中 163 次（73%）是份额没变、只因别人变了被挤走的，这 163 次共走了 29 345 px（2.4 节）。眼睛分不出谁是真挪了 |
| 作答（choose、approve 一键；稍后、回一句、定时间展开面板） | 卡经 `flipList` 换成回执（280 ms），下面的卡补位；底部弹 4.2 秒 toast“…已保存，等 Agent 下一轮整理”带撤销；纸片上的“待你选择”交叉淡成“✓ 已回应”（320 ms） | 卡、补位、纸片同一刻变；toast 在屏幕底部中央，离卡和纸片都远 |
| 下一轮整理之后 | 回执按“条目 + 问题”找（`createAnswerBook`），问题还开着时仍在；问题一关，左栏只列开着的问题，回执随卡一起淡出；纸片上也只在问题开着时写“✓” | 回执凭空消失：f22 答“打给诊所”，f23 猫看病的问题关上，卡和回执一起不见，纸片上什么都没留下；底部再弹一条 toast“Agent 已在 12:00 的整理中收到你的 1 条回应”，与桌面上正在发生的让位没有几何联系 |
| 详情 | 点纸片，右侧滑入 440 px 的阅读面板（240 ms），盖住桌面右侧 | 与被点的纸片没有几何联系；打开时右侧纸片点不到（spatial.md 已记） |
| 悬停 | 只有太小或被裁切的纸片在 220 ms 后弹出全文；其余纸片页脚出现“看详情 ›”；卡片、本人动作与纸片双向描边 | 与第三轮的概要卡不是同一套：没有停表，也没有“本轮怎么变、进了几条输入” |

### 1.2 从 D、腕上一瞥与第三轮搬什么，不搬什么

| 要素 | 出处 | A |
| --- | --- | --- |
| 切点一帧硬切，0.4 秒后才有第一个大动作 | 拨盘、D 的 `turn` | 搬。切点只换字；0–0.40 秒只确认你做过的（回执填实）和概念层，0.40 秒英雄数字翻，然后离场 → 主角 → 移位 → 进场 |
| 答一件，少一件；保存不等于收到 | D 的 `answer` 与 3b | 搬。按下的那一帧卡就原地收成回执；份额与排布要等下一轮整理读到了才动，回执上写“桌面还没变” |
| 回执跟着条目走，不随版本消失 | D 评审 4 | 搬，并落到 A 的几何上：问题关上时，回执从左栏飞到它的纸片上，留成纸片上的一行；同一问题重登记，回执留在卡上；换成另一个问题，卡上写“你答过上一版” |
| 每个元素一次只走一段，主角“端着走” | D 3.6、4.4 | 搬。纸片与卡从旧位置到新位置只有一段运动；你答过的那件用缓入缓出，其余缓出、不过冲 |
| 英雄数字差 1 滚一格，差 2 以上硬翻 | D | 搬 |
| 概念层约八成，一直动 | 拨盘、脉冲 | 不搬。A 是阅读工具，静止是默认。概念层只有上一轮的轮廓：换轮时要挪的纸片在原位留一圈灰影，1.1 秒内退干净 |
| 悬停概要卡、点击沿自身几何弹出 8 px + 引线 + 详情卡 | `motion/ix.mjs` | 搬。纸片沿自己的框外扩 8 px（四边各 4 px），引线从纸片边出到详情卡；详情卡里就能作答，不要“去回答 →” |

### 1.3 两个桌面参照

凭使用记忆描述，没有逐帧量过；时长只作量级。

- **Keynote 的「神奇移动」。** 两张幻灯片上同名的对象，切换时从旧位置、旧大小一路走到新位置、新大小，其余的淡入淡出。可取的：认得出“同一个东西”是因为它没有断，一次只走一段；要命的是同时走的太多，十几个对象一起飞，眼睛只能跟住一个。A 现在每轮挪 8–15 张纸，大半是被挤走的，所以先要让不该动的别动（2.4），再给该动的排先后。
- **看板上拖一张卡（Trello 一类）。** 卡被拿起时抬高一层，经过的列让出一个空位，放下时落进空位，空位两边的卡合拢。可取的：让出的位置先出现、落点清楚；拿起的那张始终在最上层。A 的主角（你答过的那件）同样在最上层走，经过别的纸片时不被盖住。

### 1.4 桌面 Chrome 的约束

- 60 fps 靠只动 `transform` 与 `opacity`。现有纸片的正文跟着形状裁切（`clip-path`），这一层在主线程重绘，spatial.md 已记为未解决；这次不改共用底座的画法，只给它加节拍，第 7 节量帧。
- 切点读一次布局，之后只写；左栏与桌面在同一个切点量位置。
- `prefers-reduced-motion` 时一切直接到终态，不演讲一遍。

### 2.4 位置跨帧有多不稳

同一块 978 × 520 的桌面（1440 × 900 窗口），按 composite 逐帧排，比较相邻两帧同一张纸的中心与大小（差 4 px 以上算挪了）：

| | 挪了的纸 | 份额没变却挪了 | 这些纸共走了 |
| --- | --- | --- | --- |
| 现在（每帧单独排） | 224 次 | 163 次（73%） | 29 345 px |
| 拉向上一轮的位置（稳定项 6） | 220 次 | 159 次 | 17 971 px（−39%） |

次数几乎不降，因为纸片按 `rank` 排成阅读顺序：一件变急，它前后的纸必然换位，这是“位置 = 紧急度”本身，不能拿掉。降下来的是路程：不再为了别人的一点份额变化把整张桌面重排。样张两轮：f21 → f22 从 1 247 px 降到 295 px，f22 → f23 从 737 px 降到 274 px。story 同样从 31 905 px 降到 17 889 px。为了让同一帧无论从哪一帧走来都长一样，页面从第一帧起逐帧链式排（同一桌面尺寸只排一次，29 帧约 35 ms）。

## 3 故事（story）

**一个点。** 桌面通常是满的；答掉一件，要等下一轮整理读到了，它的纸片才缩回去，桌面空出一块。你按下的那张卡原地收成回执，留在手指下；整理落地时，回执先变实，再飞到它的纸片上，纸片带着回执缩到新的位置，让出的面积变成空着的桌面。屏幕上每个元素都从原来的位置走到新位置，一次只走一段。

**英雄数字：桌面空着几份。** 样张里 f21 是 2，f22 变 0（桌面满了），按下“打给诊所”之后仍是 0（保存不等于收到），f23 整理落地变 25。它写在桌面右上角，是这一页唯一的大字（位置与字号永不变），只在一轮整理落地的 0.40 秒翻；作答、撤回、稍后都不动它。三种读法的英雄数字连成一条：脉冲是这一轮收到多少，拨盘是一共能放多少（64），D 是要你答几件，A 是答完之后桌面空出几份。

### 3.5 两层与约束

- **信息层（约八成）。** 纸片、卡片、英雄数字、计数、回执与所有字。墨黑加朱红；朱红只给登记了回应路径的问题（卡的左边条、纸片上的“待你…”、新问题描一次）；回执是墨色。
- **概念层（约两成，只在换轮的 0–1.1 秒）。** 上一轮的轮廓：要挪或要走的纸片在原位留一圈灰影（1 px 灰线加极浅的灰底），纸片走开后露出来，告诉你它从哪来；缩小的纸片外面那圈灰影就是让出的面积。只用灰，不出字与数，不用朱红；作答、撤回、展开不出灰影；静止时为零。
- **绝不动。** 英雄数字的位置与字号；左栏与桌面的分界；纸片的阅读顺序（`rank`）。动画只表现排出来的结果，不发明顺序。
- **每个元素一次只走一段**，不折返；纸片的长缩沿它自己的框。
- **先后。** 切点换字 → 你做过的先确认（回执）→ 英雄数字 → 离场 → 主角（你答的、失效的）→ 移位 → 进场 → 新问题描边。
- **不提前。** 下一轮整理落地之前，份额不动、排布不动、回执不变实、答过的卡不离开左栏。
- **预算。** 一次节拍同时动的元素：桌面最多 15 张纸（composite 的 f14、f17），左栏一般 3–5 张卡与行；进场错开 40 ms、封顶 8 个。

## 4 交互（interaction）

共用 [motion/ix.mjs](../motion/ix.mjs)，时序用它的 `IX` 常数，落在 A 的桌面上：

- **悬停**：鼠标移到纸片上（命中区比纸片四边各宽 12 px，空桌面上才算），或 Tab 到它（每张纸一个视觉上隐藏的按钮，放在桌面最前）。出概要卡：来自哪条流、几份、本轮怎么变、本轮进了几条输入、开着的问题与期限；其余纸片与左栏其余卡降到七成；卡与左栏里同一件事的卡互相描边（A 原有的联动）。换轮过渡、连播与讲一遍都停在当前时刻，离开 0.15 秒后卡淡出，再过 0.4 秒接着走。停在换轮中途时卡上不提前说后面节拍的事：份额落定（0.80 秒）之前写上一轮的份数与“还没落定”，进场（0.60 秒）之前不列本轮才登记的问题。
- **展开**：点击纸片或它的概要卡，或 Tab 后按 Enter。0 秒是切点：标题切到“这一件 · 第 23 轮 · 猫看病 12 / 64 份 · 变小 24 → 12”，桌面上方的面包屑切到“这一件”；0–0.3 秒纸片沿自己的框外扩 8 px（四边各 4 px，过冲 3.7%），阴影抬一档；0.4–0.6 秒引线从纸片朝外的那条边出去；0.6–0.9 秒详情卡从引线末端展开，贴在纸片旁边、留在桌面里。详情卡依次是：这一件的标题与份额、摘要、份额逐轮、本轮进了它、**这件事的问题（与左栏同一张作答卡，可以直接答）**、你的回应（来源处的回应加本页回执）、“依据与原文 ↗”（打开 A 原有的阅读面板）。A 自己能作答，所以不放“去回答 →”。
- **收回**：Esc、点空白、再点同一件：卡 0.2 秒收起、引线 0.15 秒缩回、纸片 0.2 秒落回。换帧、连播、讲一遍与合页顶栏选帧立即收起。键盘打开的，卡展开后焦点进卡，收回后回到那张纸的隐藏按钮。触屏：第一下是悬停，第二下展开。
- **左栏的卡**：卡上的条目名（“Smilla剂量疑超失明线… ›”）从点开阅读面板改为展开桌面上那张纸；卡、本人动作与纸片的描边联动保留。子层（story 下钻）与小事铺开后，非根层的纸片仍点开阅读面板。
- **脚本**：`window.foldA` 有与 `foldDial`、`foldWatch` 同名同义的 `hover / unhover / open / close / ixAt / ix / paused / pointOf / ixState`，另有 `index`、`go(i)`、`play()`、`stop()`、`beatAt(秒)`（把在途的换轮或作答定在某一刻，供静帧；`null` 放开）、`beat()`、`answer(id, action)`、`undo(id)`、`waiting()`、`blank()`、`papers()`、`pick()`、`nearOf(name, px)`、`tell()`、`skip()`。`scripts/check-ix.mjs` 的 16 项在本页同样跑。

## 5 实现（motion）

- **文件。** 编排在 [a.mjs](../../variants/a.mjs)；节拍表与四个部件在 [a-motion.mjs](../../variants/a-motion.mjs)：`beatList`（左栏按节拍重排）、`fly`（回执飞向纸片）、`traces`（上一轮的轮廓）、`flipHTML`（数字在节拍上翻）。[spatial-kit.mjs](../../variants/spatial-kit.mjs) 的 `createFlipBoard.update` 多了可选的 `timing(kind, id, info)`（每张纸自己的起止与缓动、进场从哪里起步、离场去哪里）与 `timer: false`，并返回这一次的移动计划；[a-layout.mjs](../../variants/a-layout.mjs) 的 `layoutPapers` 多了可选的 `previous`（2.4 的位置粘性）。两处不给新参数时行为与原来相同，原版树图不受影响。
- **一拍一个时钟。** 每次换轮或作答新建一拍，这一拍里创建的 Web Animations（纸片、卡、回执、灰影、数字）都挂在它上面：悬停时一起 `pause()`，`foldA.beatAt(t)` 把它们一起定在第 t 秒，下一拍开始前上一拍直接 `finish()` 到终态。连播与讲一遍走页面自己的 rAF 时钟（一轮 5.6 秒，慢速时 ×1.5），悬停时同样停住；页面隐藏时停播。空格由本页接管，不再用实验台的定时器。
- **桌面。** 换轮时 `timing` 按 BEATS.turn 排每张纸：离场 0.40–0.64（并入 0.40–0.80），主角 0.40–0.88（你在本页答过、问题随后关上或换掉的那件；没人答、问题自己失效的晚 0.06 秒），只换字不挪的纸 0.56–0.80，其余移位 0.48–0.80，进场 0.60–0.96、错开 40 ms、封顶 8 个；从小事一叠里出来的纸从那一叠起步，归进小事的纸缩向那一叠。作答、撤回、稍后只换那张纸上的字（0.10–0.30），桌面不挪。纸片位置跨帧稳定：页面从 f00 起逐帧链式排布，同一帧无论从哪一帧走来都一样。
- **左栏。** 卡、折叠行、回执都以条目 id 为 `data-flip-key`；同一件事的卡、回执、紧凑行是同一个盒子换脸（`data-face`），旧字在原处淡出、盒子走到新高度、新字淡入；计数与折叠行（`data-step`）在自己的拍上一帧硬翻，旧字跟着盒子走到那一刻。从折叠行补上来的卡从折叠行的位置滑出。按下之后 1.12 秒内，按下点 32 px 内的鼠标点按不接（键盘照常）。
- **回执跟着条目走。** 同一个问题重登记：回执留在左栏原位，变实。换成另一个问题：卡原地换脸，留一行“你 HH:MM 答过上一版：…· Agent 已收到，问题随后改写”。问题关上：回执在那一轮从左栏飞到它的纸片（越过一切的 fixed 层，0.40–0.88，最后三分之一淡进纸片），纸片上从此多一行“✓ 选了「打给诊所」· 已收到”，展开时详情卡里也有。确认就写在卡上，原来的 toast 撤掉；U 撤销照旧。
- **交互。** 根层纸片的正文从按钮改成 `div`，悬停与点击交给 ix：命中区四边各宽 12 px，只在空桌面上算；隐藏按钮放在桌面最前，Tab 先到它们。8 px 外扩用 CSS 的独立 `translate` / `scale` 叠在 FLIP 的 transform 上，两者互不干扰；压暗是 `--a-ix-dim`，桌面其余纸片与左栏其余卡降到七成。详情卡用 ix 的 `detailHTML`，把“开着的问题”一节换成 A 自己的作答卡（与左栏同一套 respond.mjs 控件，在卡里作答走同一拍），末尾“依据、版本与原文 ↗”打开原有的阅读面板。原来给小纸片弹全文的 `a-peek` 撤掉，由概要卡代替。子层与铺开的小事仍是按钮，点开阅读面板。
- **讲一遍。** `TELL` 写明两份数据的样张（composite f21 → f22 → 打给诊所 → f23；story f13 → f14 → 改时间 → f15，按帧 id 找下标），时间表照 3.6。“直接打开”读页面载入时的地址（`performance.getEntriesByType('navigation')`），因为 explore.mjs 载入后会把 `?frame=` 写进地址栏；另要求顶层窗口、没有 referrer、不带 `embed=1`。
- **reduced motion。** 不建拍：换轮、作答、撤回直接到终态，不出灰影、不飞回执、不描新问题，也不讲一遍；ix 自己的时序在 reduced motion 下同样直接到位。

## 6 与故事的出入

- 左栏“5 个等你 → 4”是一帧硬翻，没有滚一格；只有英雄数字在相差 1 时滚一格。
- 展开时的切点分在三处：日期处“第 23 / 28 轮”，时刻处“猫看病 12 / 64 份 · 变小 24 → 12”，标题“这一件 · Smilla已减量，24日9:30复诊”；面包屑“全部事项 / 这一件 · 猫看病”。

- 3.4 的“回执空心勾填实”实现为：飞走的回执一开始就换成“已收到”的字，0–0.30 秒从半透明变实；勾放大回落只在留在左栏的回执上。
- 离场纸片的灰影 0.90 秒起淡、1.10 秒与其余灰影同时退净。
- 讲一遍自己的悬停（6.6 秒起的猫看病）不停表；你的悬停与展开会让讲述停住，按下任意键或点按就跳到终态。
