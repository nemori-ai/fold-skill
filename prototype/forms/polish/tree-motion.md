# 原版树图 · 动画记录：参考、数据、故事

状态：2026-10-20 按第三轮的六步流程（reference → data → story → motion → direct → ship）重做[原版树图](../../index.html?frame=26)的动画与交互。第 1–3 节在任何东西动之前写下，定下一个点、一个英雄数字与三拍；第 4–6 节是照它做完之后的实现、出入与验证。原型探索，不是规范。树图怎样承载信息、承载哪类回应仍记在 [spatial.md](spatial.md#原版树图)；这次改动的动画与交互以本文为准。范本是 [home-motion.md](home-motion.md)（换轮三拍、答一件少一件、回执跟着条目走）与 [watch-motion.md](watch-motion.md)（阅读工具的概念层只占两成、只在节拍上动），两层法则与交互标准见 [CONCEPTS.md](../CONCEPTS.md#第三轮概念动画)。下面的数都由页面用同一份 `scenario.mjs` 回放现算，规则见 2.1；推算脚本只留在本机，不入库。

树图与两个概念动画有两处根本不同：它是阅读工具，坐在电脑前一格一格读，静止是默认；它能作答，工作评审的格子里直接有“批准 / 要求修改”。所以概念层约两成、只在两种节拍上动：换轮（←/→、连播、合页顶栏选帧）与作答。“丝滑”来自同一件事的格子在换轮、作答、展开之间位置连续，不靠粒子。

## 3 故事（story）

**一个点。** 面积就是注意力，而它只在整理落地时挪：你在格子里批准一件，它先在原处收成回执，面积一份不让；等 Agent 下一轮整理读到了，份额才连同别的格子一起，从旧位置走到新位置。

**英雄数字：N 件等你回应。** composite 的样张是 6 → 5（换轮）→ 4（你批准）→ 3（下一轮整理）。它是这块板唯一的大字（板头左侧，22 px 等宽，位置与字号永不变），回答场景的第一问“这两周里有几件等我”；只在两类时刻动：一轮整理落地，你作答或撤回。D 说的是同一个数，手机上排成卡，这里铺成面积。“本轮动了几格”不做成英雄数字：它几乎每轮都过半，说的是布局，不是你。

### 3.3 两层与约束

- **信息层（约八成）。** 格子、面积、字、英雄数字、回执、引线与卡。只在节拍上动。颜色沿用树图自己的：格子按根层事项的颜色，墨点 = 登记了回应路径，赭色描边 = 本轮有变化，绿色 = 你的回执。
- **概念层（约两成）。** 只有灰点：本轮输入两条一粒，从左栏右沿流向中间，采用且归到板上的落进那一格、落地即灭；其余在半路熄灭。只在换轮的 0–0.50 秒出现，静止时为零；不出文字与数字、不用颜色；本轮 0 条输入（story 的两次 review）就不落。
- **绝不动。** 英雄数字的位置与字号；板的边界；排序规则（rank）；格子的字号。动画只表现 `layoutFill` 排出的结果，不发明位置。
- **每格一次只走一段。** 一次节拍里每格从旧矩形到新矩形只有一段运动，不先缩后长；字不拉伸。
- **先后。** 切点换字 → 你做过的先确认（回执）→ 英雄数字 → 离场 → 移位 → 进场 → 新问题描边。
- **不提前。** 下一轮整理落地之前，不动面积，回执不填实；悬停在节拍中途时，概要卡不说出后面节拍的事。
- **预算。** 只动 `transform` 与 `opacity`；正文用反向缩放留在色块左上角，不用 `clip-path` 动画。

### 3.5 交互（共用 [motion/ix.mjs](../motion/ix.mjs)）

- **悬停。** 鼠标移到格子上（含格子外沿 10 px 内的板边），或 Tab 到它（每格一个隐藏按钮，在“对比”之后）：出概要卡，写来自哪条流、完整标题、几份与本轮怎么变、本轮进了几条输入、开着的问题或你的回执；其余格子降到七成；连播与在途的节拍停在当前时刻。离开 0.15 秒宽限，卡 0.12 秒淡出，再过 0.4 秒接着走。悬停输入栏或概览里的问题，对应格子描边（原有）。
- **展开。** 点格子、点它的概要卡、Tab 后按 Enter，或点输入栏与概览里指向它的条目。0 秒切点：旁白标题切到“这一件 · …”；0–0.3 秒格子四边各外扩 4 px 抬起；0.4–0.6 秒引线从格子右沿水平画到右栏；0.6–0.9 秒详情卡从引线接上的那一点沿右栏左沿展开、再向右铺满，盖在概览上。卡里是原来的详情，作答照常在卡里做，回执同时落在格子里。

- **作答。** 格子里“批准 / 要求修改”，详情卡里 A 批准、R 要求修改、其余控件；U 撤销最近一次。不再弹 toast，“已保存”只写在回执里（读屏用一个隐藏的 `aria-live`）。树图本身能作答，不加“去回答 →”。
- **钩子。** `window.foldTree` 有与 `foldDial` 同名同义的 `hover / unhover / open / close / ixAt / paused / pointOf / ixState`，另有 `index`、`go(i)`、`play()`、`stop()`、`beatAt(秒)`（把在途节拍定在某一刻，`null` 放开）、`answer(id, action)`、`undo(id)`、`waiting()`、`tiles()`、`pick()`、`nearOf(id, px)`、`tell()`、`skip()`。`scripts/check-ix.mjs` 的 16 项在本页同样跑。

### 4.3 取舍

- **字不拉伸、色块裁字。** 正文放在色块里面，色块沿自己的矩形平移与缩放，正文按同一采样（每段 14 个关键帧、线性插值）反向缩放，钉在色块左上角、被色块裁住。不用 `clip-path`，也不在关键帧里写 `transform-origin`，只动 `transform` 与 `opacity`。
- **换了字的格子逐个部件交接。** 内容变了的格子把旧正文留成“幽灵”（旧尺寸、旧尺寸类，所以旧字不重排），新旧正文按 `data-part`（标签、份数、标题、提问、回执、摘要、页脚）配对：同字的从旧位置滑到新位置，换字的旧淡出、新淡入，份数与留白数在落定时一帧翻，不交叉淡化。
- **回执只有一个部件名。** 回执在格子里（按钮的位置）或标题下一行，答的是这一版、上一版还是已关上的问题都叫 `receipt`；下一轮读到时新旧回执配成一对，新的一行立刻写“已收到”、实心点 0–0.30 秒放大填进空心勾，再随格子移位，不在半路淡出重来。
- **回执跟着条目走。** `receiptOf` 按条目取本页最近一次作答，再与这一帧的问题比：同一个问题 = 回执，问题换了 = “你批准了上一版 · 已收到”，问题关上 = 一行小字（story f05 导出那格“你选了「固定模板」· 已收到”）。读屏用一个隐藏的 `aria-live`，不再弹 toast（“复制 JSON”的提示保留）。
- **作答不被停住。** 悬停与打开的卡会停住在途的换轮与连播；作答与撤回是你自己的动作，回执在你悬停或看卡时照常画完。
- **详情卡就是右栏。** ix 的详情放在右栏的位置上、和右栏同高，内容是原来右栏的这一件（作答、为什么在这里、依据、版本……），概览留在它底下；作答在卡里做，回执同时落在格子里，卡里的字原地换掉，位置与滚动不变。右栏在板子下面时（窄屏）卡也在那里，引线向下，打开后把它滚进视野。
- **弹出不拉字。** 外扩 4 px 是格子背后的一块底板按比例放大，格子本身与字不缩放；打开时板子的裁切临时放开，贴边的格子也能外扩。
- **灰点。** 本轮输入两条一粒、最多 120 粒，从左栏右沿出发；采用且归到板上某一格的（拨盘的归属规则 `rounds[i].events[].root`，收在小事块里的落进小事块）落进那一格、落地即灭，其余在半路熄灭。只在顶层、不对比、左栏在板子左边时画；story 的 review 轮没有输入，就不落。悬停时降到四成。
- **连播。** 一轮 = 换轮 1.0 秒 + 读 max(2.2, 2.9 / 速度) 秒；悬停、打开的卡停住累计，移开 0.4 秒后从停住处接着计时（第一轮也要等满，所以按“播放”后约 3.9 秒才换第一轮，与原来的 3.2 秒相近）。
- **链入。** `?item=` 落地时那一件直接以卡打开（等在途节拍走完）；打开卡时地址带上 `item`，收回时去掉。
- **减少动态时** 不建节拍，一切直接到终态，ix 的弹出、引线与卡也直接到位，不讲一遍。

### 4.4 与故事的出入

- **composite 那一格自己没有让。** f22 批准 #13572 之后，f23 这一格仍是 6 份（问题换成“三个旧 PR 推到哪天再看”）；这一轮让出份额的是母亲 24 → 6、猫 24 → 12，留白 0 → 25 长出来，回执跟着这一格从左下移到上排中间。“答掉的缩小沉下去”在 story 里照字面发生：导出那格 12 → 6、问题关上、回执留成小字。
- **悬停也停住新问题的描边。** 描边是换轮这一拍的最后一段（0.96 起 1.6 秒），讲一遍 7.8 秒的悬停落在它中途，描边就停在半透明处，直到移开。照“悬停停住在途节拍”的规则没有特判。
- **两个计数。** 英雄数字只数这一层的格子（与 D 同口径），右栏概览的“N 个问题等你”数的是全部开着的问题（含子事项）；story f04 两者是 4 与 6。没有改右栏。
- **概要卡里回执写“已收到”的门槛** 用本轮输入落定（0.50 秒），不是回执填实的 0.30 秒：ix 的卡只按 inputs / share / asks 三道门槛重写。
- **引线穿过右边的格子。** 引线从被打开那格的右沿水平走到右栏，路上的格子已降到七成，没有绕行。
- 760–999 px 的版式（右栏在中间一列、最右一列空着）是原有的，卡跟着右栏走，没有改版式。
