# pulse · spec：参考视频 A 为什么有效

状态：2026-10-19，动画形式 `pulse` 的第 1 步（reference）。只记参考视频的节奏与搬到 Fold 上的取舍，第四轮在末节补了交互的节拍；故事见 [story.md](story.md)，数字见 [data.json](data.json)。

参考：A「CLAUDE BRAIN」搜索树，1290×1544 竖幅，60fps，24.73 秒（1484 帧），首尾相接循环。读法：ffmpeg 每 0.25 秒抽帧拼图看过渡；主图区逐帧平均亮度（YAVG）找心跳；场景分找剪辑；底部流水线四行逐帧亮度找切换；y=450 一行的最亮点追闪电路径。全片饱和度为 0：纯灰阶。

## 节奏（pacing）

- **一个镜头到底。** 全片场景分最大 0.042，没有一处剪辑，也没有推拉摇移；24.5 秒的画面接回 0.4 秒（左侧小扇刚亮），循环无缝。
- **心跳约 2.9 秒。** 主图亮度 8 次峰值：2.5 / 5.4 / 8.25 / 11.25 / 14.25 / 17.0 / 20.0 / 23.0 秒；基线 29.5，峰值 40.7–44.5（高出 38%～51%）。上升 0.5–1 秒，回落 0.5–0.75 秒，峰后常留 0.5–1.25 秒静场（3.25–4.5、7.25–7.75、15.25–16.25、23.5–24.5 秒）。
- **三层时钟互不对齐。** 流水线约每 0.67 秒（40 帧）跳一格，四格一圈 2.67 秒；弧约每 4 秒起一次（约 0.6 / 4.6 / 8.9 / 12.6 / 16.5 / 20.6 秒），2.25–2.5 秒扫到顶；云闪约 2.9 秒一次。三者不锁相，8 次心跳没有两次长得一样，不显机械。
- **焦点最慢。** 闪电路径全片只改道两次：11.4 秒与 20.15 秒（y=450 处的 x 坐标 372 → 327 → 425）。周围越忙，它越稳。

## 第一个动作（first motion）

- 0–0.25 秒完全静止，只有闪电与暗树。
- 0.25 秒根部放射线微亮；0.375 秒根左侧一个小扇（被剪掉的子树）点亮，根周围浮出一道极淡的半圆参考线；0.5–0.75 秒右侧小扇也亮，第一批折线笔画出现；0.875–1.125 秒一道稀疏的锯齿弧离根约四成高。
- 要点：**第一个动作小、低、贴着锚点**，亮度只有峰值的零头；大动作从它长出来，不从画面外砸进来。弧先给轮廓（稀疏粗笔，1.0 秒）再给密度（细密光带，2.5 秒）。
- 弧的缓动：半径 0.75 秒约三成高，1.5 秒约六成半，2.0 秒约八成，3.0 秒约九成半并散掉。先快后慢，到顶变细变暗。

## 剪切节奏（cut rhythm）

没有镜头剪辑，"剪"由离散量的单帧硬切承担，连续量一律缓动：

- 流水线高亮：0.57 / 1.23 / 1.93 / 2.63 秒……全片 37 次，约等距（间隔 0.53–0.73 秒）。
- 顶部标签框换字：落在云闪峰值上（2.2–2.4、5.1–5.3、8.1–8.6、11.0–11.5、14.0–14.5、17.0、19.8–20.3、22.8–23.3 秒），换字被闪光掩护。
- 底部小扇在每次云闪同步爆亮（2.25–2.5、5.0–5.5、8.0–8.25、11.0–11.25 秒……）：主图、标签、小扇同一帧回声。
- 换字从不落在弧的起点：动作先起，字后换。

## 搬到 Fold 上：保留什么、丢什么

1. **动画就是过程。** 保留：可读的动作都对应回放里的事实。丢：A 面板上装饰性的跑分。按官网定位放宽为两层：概念层可以装饰，信息层必须有出处（见 story.md）。
2. **一个中心机构，面板做回声。** 保留：根 = 64 份，同一事实在主图、64 格带、问题面板同一帧变。丢：顶部平行坐标图，Fold 没有对应的量。
3. **密度出规模，单点给焦点。** 保留：云是密的，亮的必须少。A 的闪电 → Fold 的朱红线，只给新登记的问题，一轮通常 0–2 条。
4. **有节奏有阶段。** 保留：约 3 秒的心跳、四格流水线、峰后的静场。改：信息层锁在节拍上，错拍的时钟只留给概念层；弧的方向反过来，A 从根向外扩（搜索变宽），Fold 从外向根收（整理变少）。
5. **质感。** 保留：近黑而非纯黑（最暗处 Y≈9/255），满屏细线与星点把主图平均亮度抬到约 12%；细线、余辉、先快后慢的缓动、60fps、canvas 画主图。改：A 纯灰阶，Fold 只加一种朱红。丢：仿终端的小字堆砌与伪精确标签。

## 交互的节拍（2026-10-19 第四轮加）

参考视频 A 没有交互，这一节沿用份额拨盘从视频 B 取的三条（[dial/spec.md](../dial/spec.md)）：离散量一帧硬切，第一个动作在切点后 0.4 秒，连续量用 ease-out、带约 3.7% 的过冲。整理脉冲上的对应：

- 展开：0 切点（本轮时钟停住；信号与旁白、三块面板一帧切到这一件）→ 0–0.3 秒枝条与它在根上的格子沿自己的射线外推 8 px（ease-out，过冲 3.7%）→ 0.4–0.6 秒引线从枝梢沿射线出到外沿之外，再连到卡 → 0.6–0.9 秒卡从引线末端展开，先沿接上的那条边、再向外。
- 收回（Esc、点空白或再点同一根枝）：0–0.2 秒卡收起 → 0.2–0.35 秒引线缩回 → 0.35–0.55 秒枝落回 → 一帧切回旁白与面板 → 0.4 秒后时钟接着走。

悬停没有切点：概要卡 0.15 秒淡入，其余标记 0.15 秒降到七成（概念层四成）；离开后 0.15 秒宽限、0.12 秒淡出，0.4 秒后时钟接着走。和 A 的“焦点最慢”一致：被看的那一根不动、不闪，动的只有它周围变暗。
