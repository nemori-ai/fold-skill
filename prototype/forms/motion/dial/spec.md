# 份额拨盘 · spec：参考视频 B 为什么有效

状态：动画形式 `dial` 的第 1 步（reference），2026-10-19，原型探索，不是规范。参考 B：1080×1350、60fps、24.0 秒的纸底“工作室仪表”。下面的秒数来自按 0.25 秒与 60fps 抽帧、分区帧差（环带、车道、左侧线束、底部仪表、标题卡）和实心黑块追踪；抽帧只留在本机，不提交。

## 节奏（pacing）

- 整段 = 6 步 × 4.00 秒，像节拍器：标题卡在 0、4、8、12、16、20.000 秒换字。没有片头片尾：第 0 帧转盘、小虫、线束已经在动（环带帧差 14.3，是第一秒里最高的），结尾停在第 6 步，不淡出。
- 每步里涌动两次：车道区帧差约每 2.0 秒一个峰，落在步内 +0.75 与 +2.75 秒（9.7–16.7），谷在 +1.5–1.75 与 +3.5–3.75 秒（2.4–7.0）。转盘按 ease-out 分两段往前拨，环带帧差最低也有约 6，从不静止。
- 数字不跳：顶栏五个计数（24/6/10/18/0）24 秒里没变过，只有下面的分段进度条推进。底部八块仪表帧差只有 0.5–0.8：指令栏约 2 秒加一行（050 在 0.5 秒，051 在 3.9，052 在 4.5，053 在 7.9），新行加粗、旧行转灰；代码栏一步打一行；派工条在一步里线性填满（0.5 秒刚起，2.0 过半，3.9 将满，4.5 记 done）。

## 第一个动作（first motion）

- 0.000 标题框是空的；0.067 “REFERENCE”以灰色浮现，0.133 定稿。最先出现的是字。
- 0.000–0.400 没有游标（60fps 逐帧找不到实心黑块），只有质感在动。
- 0.417 黑游标落在环上；0.40–0.60 一束黑线从左下甩起、收进游标；0.67 注释框浮现，0.75 定稿。
- 这 0.4 秒每步都一样：游标在 4.400、8.400、12.40、16.417、20.40 秒回来。环上小字自己写着 `first motion 0.4s`、`ease: out-cubic`、`overlap 0.1`、`stagger: 45ms`，与实测相符。

## 剪切节奏（cut rhythm）

- 出：+3.73 注释框开始淡出（3.733、19.73 半透明，3.80、19.87 消失），线束在最后约 0.5 秒散开，游标留到 3.983。
- 切：只有一帧。4.000 与 16.000 秒标题清空、游标与线束撤掉、高亮车道换一条、仪表跳一格，底部帧差从 0.55 跳到 3.1–3.7，前后帧都回到 0.55；转盘、小虫、细线不切，环带帧差 13.9 对前一帧 10.3，没有重新取景。
- 进：+0.07–0.13 标题，+0.40 游标与线束，+0.67 注释。每步先留 0.4 秒没有焦点。六次切点一模一样，变化全在内容。

## 为什么有效

1. **两层。** 承载信息的只有标题卡、进度条、游标和它那条车道上约 6 个黑标签、注释框、指令栏与派工条；其余是质感：上百只红虫、环上字形、灰线、热图、波形、路由表高亮格（0.5、2.0、3.9 秒各不相同，与步骤无关）。B 自己就是大约八成质感、两成信息。
2. **亮的极少。** 实心黑只给游标、当前车道的标签和标题；红色给了“量”，不给焦点。
3. **一件事同时说三遍。** 每个切点上标题卡、顶栏进度、游标位置、派工条一起换。
4. **信息硬切、质感不切。** 4 秒一跳不显得卡；0.4 秒空白让每次焦点落下都被看见。

## 搬到 Fold 上：保留什么、丢什么

| 要素 | 保留 | 丢掉或改 |
| --- | --- | --- |
| 1 动画就是过程 | 信息层每个动作对应一个数据事实：扇区角度 = 份数，游标 = 要紧的问题，车道上的墨色记号 = 本轮真实输入 | B 的车道从环往外运（AGENTS CARRY EVERY FILE OUT）；Fold 的输入往环里进。质感层不必逐个对应，两层分工见 story.md |
| 2 中心机构与回声 | 一个环承载全部；切点上环、计数、日期、仪表同一帧换 | B 的计数是静止装饰；Fold 的本轮读、采用、声明在切点硬翻，环上件数与留白在份额落定时翻，问题与要紧在游标落下时翻，只有累计输入在涌入段滚动 |
| 3 密度与单点高亮 | 一个实心黑游标；车道上成百个灰记号 | B 把红给了“量”；Fold 的朱红只给等你回的问题 |
| 4 节奏与阶段 | 一轮 4.00 秒；切后 0.4 秒没有焦点；步内两次涌动对应两次信息落点；首次打开先静 0.4 秒再数出刻度（motion 步的导演意见），之后的循环与连播没有片头 | B 的六步工作流；Fold 一轮四段：输入涌入 → 归并压缩 → 份额分配 → 回应路径 |
| 5 质感 | 纸白底、等宽字、细线、ease-out 带少量过冲、60fps | 像素小虫是吉祥物式拟物（第一轮已否定“拟物套壳”），改成抽象短划与点；B 是 4:5 竖幅，官网 hero 用横幅，左环右车道不变 |

一轮的时间表（连播时每轮都按它走）：0 切点（旁白、日期、计数硬翻）→ 0.40 第一批输入到环 → 1.00 归并（吸进扇区、停在环外或熄灭）→ 1.30 份额落定（0.5 秒，过冲约 3.7%）→ 1.90 游标甩出（0.5 秒，快起、过冲约 3.7%）→ 2.40 落定、注释浮现 → 2.70 线束从画面左缘收进（每根 0.3 秒，相邻错 0.1 秒，最多铺开 0.4 秒）→ 留 1.3 秒读 → 4.00 硬切，注释与线束随切点撤掉。与 B 不同：B 在 +3.73 收注释；这里注释与线束留到切点。
