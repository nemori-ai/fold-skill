# Fold 时光机原型

用于回答：假设 Agent 已经合理整理输入，工作与生活交织的两周会形成怎样的状态演变？原型可作为体验站发布，仍为独立实验；Fold CLI 尚未实现。

## 运行

在仓库根目录运行：

```sh
make prototype
```

打开 http://127.0.0.1:4173 。只需 Python 3，无需安装前端依赖。预览服务禁用缓存，修改后刷新即可看到最新版本。所有内容在浏览器内存中回放，不连接真实账户，不持久化数据。

## 三种视觉表达

在同一路径加 `variant` 即可进入本轮探索，底部可以切换方案，保留当前时刻、层级和选中的事项：

- [A · 空间排布](./index.html?variant=a&frame=6)：事项像独立纸片聚在中部，真实留白散在周围和间隙。
- [B · 时间展开](./index.html?variant=b&frame=6)：顺着同一事项的份额轨迹，理解怎样走到当前局面。
- [C · 流动形态](./index.html?variant=c&frame=6)：用 Three.js 液体体量与连续形变辅助感知，精确份额看预算带与 JSON。

三版与原版共用同一故事和回放数据。底栏的「选择回放片段」可直达冷启动、合并、用满预算和细节；「原版」可返回已有实现。「状态」打开数据核对区，可查看完整状态 JSON、原始输入、声明与回执、变化对比。←/→仍逐帧，Alt+←/→切换方案。

B 在桌面上将历史与此刻等宽并列，右侧详情独立滚动。悬停、键盘聚焦和选择会联动同一事项的历史带、当前截面与标签；切换时连续展示几何变化，也可点击「重播过渡」。

C 通过液滴内部的透光与折射光带标记选中，文字在静置时固定。持续的表面蠕动已放缓至前一版的 40%，帧间与层级切换的过渡速度不变；点击和指针移动不再引起水波纹。选中不改变液滴位置、轮廓计算或份额，减少动态效果时保留静态材质。短窗口下允许页面纵向滚动，避免挤压文字。

原版与 A 的条目面积按份额比例布局；B 在记录节点和当前截面用带的粗细表达份额，连接区用于帮助追踪变化；C 的液体体量只辅助比较，准确份额由独立预算带与 JSON 表达。各方案都保留未分配份额。

液体版使用已随原型保存的 [Three.js 本地模块](vendor/three/README.md)，浏览器需支持 WebGL 2；不可用时仍提供同数据的可读列表与准确份额。实验假设、表达边界和待评审问题见 [EXPLORATIONS.md](EXPLORATIONS.md)。

## 原版操作

- 从真正的空状态开始：第一帧为 r0/e0，没有输入与提交。接着只纳入一件事，再补入生活背景，份额依次为 0 → 6 → 18 → 49；初始阶段有独立跳转入口。
- 播放、逐帧前后跳转，或拖动时间轴到任意时刻。两次批处理之间业务状态保持，时间投影继续流逝。
- 切换状态时，同一条目会连续移动和缩放；合并的条目会汇到一起，下钻会从父项展开细节，返回时再收回。可用「重播过渡」再看一次，打开「慢动作」观察注意力怎样转移。
- 左侧显示这一帧的原始消息及采用、重复、噪音、暂缓的理由。
- 点击 Pinboard 条目查看详情；有子项时点击箭头进入独立预算的下一层。
- 右侧可以在排版详情与原始 JSON 之间切换。顶部「完整 state」始终可查看整份状态。
- 点击「对比状态」，选择基线与当前帧，查看同尺度的两个 Pinboard 和字段变化。
- 空格播放／暂停，左右方向键逐帧，Esc 返回上层。URL 保留帧、层级和对比基线。

两个动画演示入口：

- [两张账单合成一张](./index.html?frame=5)：向前一步看归并，再退一步看原来的两条线索展开。倒放是在查看合并前的历史，不代表生产系统有 split API。
- [导出发布的两级细节](./index.html?frame=3)：进入「v0.8导出：模板编辑待定」，再进入「旧机操作验证与回滚演练」，用返回或 Esc 逐层收回。

人物和私人消息为演示创作，公共事实的官方来源见 [STORY.md](STORY.md)。故事中的 Agent 决策已预先编排，不能据此宣称真实 Agent 或模型达到相同判断质量。

## 评审留白

通过实际播放继续判断：取舍是否自然，时间关系是否清楚，动画中的注意力转移是否可读，哪里需要反复查 JSON，以及噪音是否影响阅读。三种视觉方案仍在比较；公开体验不代表已选定产品方案，也不代表真实 Agent 判断质量或 Fold CLI 已通过验收。
