# 林苒的两周

这是供交互原型播放的创作情境，不是任何人的聊天记录。人物、六人团队「拾页」、客户「远川工作室」、私人消息、指标、金额、日程与所有执行结果均为虚构。故事发生于 2026 年 10 月 12—25 日的上海。

林苒准备向试用客户开放一个新版本，同时要兑现陪妈妈出门的约定、处理家中渗水，并与一位反复改期的候选人坦诚讨论团队。两个星期没有一条直线：试用数据晚到，技术修复只解决一半，物业的“修好了”被新照片推翻，完成的成果也要与正在发生的事情争夺注意力。

## 规模与结构

- 37 个有序时间帧、112 条输入；84 条纳入判断，12 条噪音、10 条重复、6 条暂缓。未形成新板面事项的输入占 25.0%。其中 3 条是通过登记按钮给出的反馈，1 条是宿主的到点提醒。08:30 从真正空白开始，第一条输入在 08:34 到来；来源的观测时间保留本次整理时间。
- 冷启依次呈现 0 → 6 → 18 → 49 份：空白、只有发布范围、加入家人约定、再到原来的 09:10 多渠道整理。前两批不预知客户、账单、性能或招聘，也没有子层与精确截止；细节随有依据的新输入逐步形成。
- 八条主题线：发布、试用、运行体验、费用、家人、维修、招聘、技术线索。费用起初是两个尚未确认身份的叶子，核对后合并。
- 发布、试用、体验、家人、维修、费用与经验交接都有可展开的细节；发布条件再展开到旧手机验证与回滚演练。
- 初态 `cold-00` 没有输入或写入（`batch: null`），保持 r0/e0。其余帧的 `batch` 是故事作者预先写好的 Agent 判断，不是前端按输入频率、时间或告警等级推算的重要性。原型引擎按契约重放声明。
- 宿主一侧另有反馈与时间记录，不进入状态：每个“需要你”的输出版本登记期待与可用反馈动作（`frame.asks`），回应先前问题的消息标注目标与动作（`event.feedback`），每帧记录调用原因与窗口（`frame.signal`）。含义见[领域模型](../docs/domain-model.md)。
- 所有层遵守 64 份预算。根层两次到达 64，具体缩小或撤下的条目都带原因；本故事没有使用手动份额覆盖。

## 值得停下来的帧

| 帧 | 故事 | 要体验的行为 |
| --- | --- | --- |
| cold-00 → cold-02 → f01 | 从空白，到一件交代，再到工作与家人的约定 | 状态由已收到的信息逐步形成；09:10 才首次展开有依据的细节，旧条目继续用原 ID 更新。 |
| f03 → f04 | 妈妈不想再等到楼下才知道取消 | 批注先保存，再被确认；反馈改变重要性。 |
| f04 | 财务邮件与工程截图指向同一账单 | 同层叶子合并，旧身份与来源留存。 |
| f05 | 真样表暴露口径不一致 | 预算满载时，Agent 明确缩小已有决定与委派事项。 |
| f06 | 同一个告警再次出现 | 检查有记录，面积、摘要与业务更新时间不变。 |
| f07 | 前端取消后，后台仍在计算 | 最初只有一份的技术线索开始重要。 |
| f10 → f19 | 招聘与随手记先放下，后来回来 | 明确撤下，按原 ID 恢复，不制造两个新事项。 |
| f13 → f15 | 完成的发布挡住了周末 | 完成不自动消失；用户决定成果保留多大。 |
| f14、f24 | 林苒对发布成果点「收下」，对暂存列选择「先隐藏」 | 已阅与决定是不同反馈；它们关联登记过的输出，下一轮由 Agent 解释。 |
| f17、f27 | 时间向前，没有新输入 | 零事件也要重看：f17 的东馆资料已过复核时间，改写为最后已知并待出发前确认；f27 没有新判断，只记检查。不因到期自动降档。 |
| f29 → f30 | 苏禾提议周六面谈，林苒选择明早再提醒 | 稍后提醒不是已阅；到点输入关联原反馈，Agent 按现在的事实重新判断。 |
| f20 → f23 | 费用、业务误解、后台补偿交织 | 相似告警不一定重复，重复消息也不一定重要。 |
| f28 | 画图发现没人接住失败任务 | 技术线索变成组织责任，不能只靠修代码结束。 |
| f34 | 两周之后还有未完的事 | 不追求虚假清零：月底账单、合作方式、扩展范围和对外处理窗口仍有未定内容。 |

## 公共事实与边界

以下三条已查阅官方公开来源，链接也保存在 `scenario.publicSources`，关联输入带 `publicSourceId`。核查日为 2026 年 10 月 10 日；公共资料只是背景，不能认证演示消息发生过。

- [web.dev：Interaction to Next Paint](https://web.dev/articles/inp) 解释 INP 与常用 p75 阈值。故事中的 43 个样本和所有测量结果是虚构，不把官方阈值映射为 Fold 重要性。
- [MDN：AbortController](https://developer.mozilla.org/en-US/docs/Web/API/AbortController) 说明可中止 fetch、响应体读取与流。故事对服务端任务、幂等和补偿的描述是自创故障情境；官方资料并未保证应用服务器会取消业务工作。
- [上海博物馆：东馆参观指南](https://www.shanghaimuseum.cn/mu/frontend/pg/m/service/visit-east) 提供地址和常规开放时间。故事中见面与参观是创作，不代表已预订，也不保证未来特定日期正常开放。

这份数据没有连接私人渠道，没有执行付款、预约、发消息、招聘或发布。它展示的是“收到什么、为何这样整理、结果如何变化”的可回放样本。
