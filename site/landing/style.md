# 入口页与整站 · style

状态：2026-11-03 第三轮：首屏与第 2、3 节按新结构重做（见 [story.md](story.md)），本文相应补了首屏的组件与动效；同日之后第 2 节的图改成三幕、全页少写数字、例子换成白话，本文的“第 2 节”动效与组件已按这一版写；其余仍是第二段的样子。第二段已实现：入口页在 `site/.vitepress/theme/FoldLanding.vue`（令牌定义在 `.fl` 上），文档页的主题变量在 `site/.vitepress/theme/style.css`，字体子集在 `site/fonts/`。叙述与节拍见 [story.md](story.md)，技术约束与验收见 [spec.md](spec.md)。

**一句话方向：一张印着刻度的纸。** 纸白底、墨黑字，画面由真实的点、刻痕、格子和数字构成；朱红只出现在“等你回应”的地方；动作都在原地发生。第三轮的首屏没有英雄数字：最大的字是标题，画面是“这一刻的全部”铺成的一片点和一扇随处境改形的窗。

不要的东西：高光、投影、毛玻璃、纸纹、设备反光、渐变字、满屏粒子、装饰性的循环动画、品牌绿。现在线上首页是 VitePress 默认的深色主题加一张截图网格，新方向把它换成和原型同一张纸。

## 颜色

用 OKLCH，与原型的 `forms.css`、`sketches.css` 同一组色相。每个颜色只有一个意思。

| 变量 | 值 | 只用于 |
| --- | --- | --- |
| `--paper` | `oklch(0.975 0.006 95)` | 页面底色（原型纸白） |
| `--paper-2` | `oklch(0.992 0.004 95)` | 卡片面、回执 |
| `--ink` | `oklch(0.21 0.014 155)` | 正文、标题、大数、刻痕、尺框 |
| `--ink-2` | `oklch(0.47 0.014 150)` | 次级文字、刻度 |
| `--ink-3` | `oklch(0.68 0.010 140)` | 第三级文字、轴标、暗下去的东西 |
| `--rule` | `oklch(0.885 0.008 95)` | 细线、分隔、卡边 |
| `--fold` | `oklch(0.82 0.008 95)` | 被折掉的输入（灰短桩） |
| `--seg` | `oklch(0.38 0.012 150)` | 拍 2 里尚未分回合的份额段 |
| `--agent` | `oklch(0.80 0.008 140)` | Agent 那边的份额（不用你动） |
| `--ver` | `oklch(0.60 0.19 35)` | **等你回应**：要紧的那件、按钮描边、回应的线、等你的数 |
| `--ver-soft` | `oklch(0.86 0.06 40)` | **等你回应、可以晚点**的那几件（与腕上一瞥的“暗朱红”同义） |

- 朱红的检验：把页面上所有朱红圈出来，每一处都应能回答“这是在等你回应吗？”。答过的事、新闻、品牌、链接悬停都不用朱红。
- 入口页固定纸白浅色，不跟系统深色走，也不显示外观开关（导航栏、菜单里的开关与“更多”浮层都藏起来）：构建时去掉这一页的深色预检脚本，脚本运行后 `theme/index.mjs` 在这一页把 `dark` 类挡在 `<html>` 外，离开时恢复读者自己的选择，不改它的设置。文档页保留外观切换，深色时用“墨底纸字”：纸 `oklch(0.19 0.012 155)`、墨 `oklch(0.93 0.008 95)`；文档里不用朱红。
- 对比度：`--ink` 在 `--paper` 上约 15:1，`--ink-2` 约 6.5:1，`--ink-3` 只用于 12px 以上的轴标与压暗的图形（约 3.3:1）。

## 字体

中文网页字体动辄几 MB，所以只给极少的字用网络字体，其余交给系统。

| 角色 | 字体 | 怎么来 | 体积 |
| --- | --- | --- | --- |
| 数字与拉丁展示（64、158、118、1、字标 Fold） | Instrument Serif（OFL） | `0–9`、`Fold` 与 `%+−/.·×`，21 个字形 | 2.5 KB |
| 中文展示标题（入口页 class 含 `fl-h` 的标题与六张卡的名字） | Noto Serif SC 700 的子集（OFL），站内叫 Fold Serif SC | 从组件源码收集用到的字，128 个 | 24.0 KB |
| 文档页 h1 里入口页没有的字 | 同上，第二个文件 | 从各篇 h1 收集，221 个；`unicode-range` 只列这些字，入口页不会下载它 | 41.4 KB |
| 正文与说明 | 系统字体：`-apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif` | 不下载 | 0 |
| 数据标注（时间、条数、帧号、账） | 系统等宽：`ui-monospace, "SF Mono", Menlo, Consolas, monospace` | 不下载 | 0 |

- **子集怎么做（不加依赖）。** `node scripts/landing-fonts.mjs` 收集上面那些字，向 Google Fonts 的 css2 接口按 `text=` 取子集 woff2，存进 `site/fonts/`（自托管，运行时不请求第三方），生成带 `unicode-range` 的 `theme/fonts.css` 与清单 `site/fonts/subset.json`。文案改了字要重跑；`node scripts/check-landing.mjs` 会核对标题的字都在子集里。漏字时回落到系统宋体（`"Songti SC", serif`），不会出豆腐块。
- **许可。** 两种字体都是 SIL Open Font License 1.1。两份许可全文与版权行合在 `site/fonts/OFL.txt`，随站点发布在 `/fonts/OFL.txt`，入口页页脚链到它。子集是修改版，在 CSS 里以 Fold Serif SC 的名字使用；随字体取得的两份许可都没有声明保留字体名，改名是为了不与完整的 Noto Serif SC 混淆。
- **加载。** 数字字体在每一页 `preload`（字标在导航里）；入口页另外 `preload` 中文标题子集；`font-display: swap`。首屏动画是纯 CSS、首绘即开始，不等字体：几何不依赖字形，换字形只影响文字。
- **去掉 VitePress 自带的 Inter。** 主题入口改为 `vitepress/theme-without-fonts`；现在线上首页首屏的 67 KB 字体就是它。
- **字号（第三轮）。** 首屏标题手机 28px、iPad 40px、桌面 34–46px（`clamp`）；第 2–4 节标题手机 24px、iPad 32px、桌面 34px；首屏窗里的“1”手机 56px、iPad 起 74px；账与说明 13–14.5px。下面是第二段时的字号，第 4 节与六张卡仍用：
- **字号（第二段）。** 手机：64 为 172px、拍的大数 76px、页面标题 31px、节标题 23–26px、正文 15px、说明 14.5px、等宽标注 11–12px（最小 10px，只给轴标）。桌面：64 为 330px、拍的大数 120px、标题 50px、节标题 28–34px、正文 17px。数字一律 `font-variant-numeric: lining-nums tabular-nums`，计数时宽度不跳。
- **中文排版。** 标题字距 0.01em、行高 1.25–1.36；正文行高 1.6–1.7；中英文之间留空格（与仓库文档同一规范）；标题手动断行，不让“份。”这类孤字掉到下一行（静帧第一版就出过这个问题）。

## 栅格：64 份就是栅格

- 尺有 64 格，栅格也按 64 推：内容宽 W 等分 8 大列（64 = 8 × 8，每大列 8 格），大列之间的沟就是尺上的刻度间隔。
- 手机：左右边距 16px，内容 358px，4 大列（每列 16 格，约 89px）；舞台的车道标签占左侧 44px，车道与尺共用余下的 314px。
- iPad：边距 32px；竖 8 大列、内容 756px；横按桌面排。
- 桌面：边距 80px，内容最宽 1280px（= 64 × 20px），8 大列、沟 32px。首屏标题与说明占 1–3 列，场与窗占 4–8 列（第二段时是 64 占 1–3 列、标题占 4–8 列）；第 2 节文字 1–3 列、图 4–8 列并伸到屏幕右边；第 3 节六列；第 4 节叙述区文字 1–3 列、舞台 4–8 列。
- 垂直节奏 4px 基线；节与节之间手机 56px、桌面 120px。
- 触控目标不小于 44 × 44px（按钮、卡、gallery 块、桥的格子）。

## 动效语言

### 首屏（第三轮）

首屏只演一次、停在“复盘”，时刻的唯一出处是 `landing.mjs` 的 `MOMENT`（分镜见 story.md）。它的动作是：

| 动作 | 什么时候 | 怎么动 | 时长与缓动 |
| --- | --- | --- | --- |
| 铺 | 打开页面 | 一块纸色盖板带着一根 1.5px 的墨色播放线从左往右滑开，两周一列列露出来；点本身不动 | 900ms，linear，首绘后 100ms 起 |
| 暗 | 窗第一次张开 | 场里全部点整层降到 14% 不透明度，原地，不移动；这一扇窗用到的点在上面一层留着 | 450ms，ease-out |
| 亮回 | 换到更宽的处境 | 那一扇窗多用到的点整层淡入（墨或朱红） | 300ms，ease-out |
| 改形 | 换处境 | 窗从中心改宽、改高、改圆角：圆 → 1.7 : 1 → 整宽；旧内容先收 | 张开 420ms `--e-out`（从 0.86 倍），改形 650ms `--e-yield` |
| 换 | 窗有了形状之后 | 窗里的内容淡入：一个数与一行字 / 一张面积图 / 26 根柱；账同时先出后进 | 280ms；柱从左到右各自在自己那一列下面升起（scaleY 自底），450ms，错开 24ms |

- 点处境按钮：同一组状态，用过渡切换（窗 650ms，旧内容 140ms 先收，新内容在 380ms 后淡入，亮的层 300ms）。
- 不飞：没有一个点离开它的位置，窗外的东西只暗不动。
- 第 2 节演三幕，只演一次，进视口触发（时刻的唯一出处是 `landing.mjs` 的 `WHY`，分镜见 story.md）：
  | 幕 | 怎么动 | 时长与缓动 |
  | --- | --- | --- |
  | 1 各自 | 各行的条从左长出（scaleX 自左），从上到下 | 每行 420ms `--e-out`，错开 45ms |
  | 2 加在一起 | 每一行复制一段，从自己那一行平移并压扁着落进最后一行，首尾相接（translate + scaleY）；落走的那一行原地淡到三成 | 每段 560ms `--e-yield`，从下往上错开 55ms，1.55 秒起 |
  | 3 换比例 | 比例尺缩小：最后一行与上面每一行同一条缓动往左缩（scaleX，原点在左），总和正好顶满整宽；各行淡回全墨；比例那行字先出后进 | 1400ms `--e-yield`，3.5 秒起 |
  | 收尾 | 图下一行字淡入 | 320ms，5.05 秒起 |
- 第 3 节一行一行出现（错开 150ms），小图沿用第二段桥的画法就地画出。都只演一次。

### 第 4 节与其余（第二段）

只有五个动词，全都在原地或沿一条轴发生，只动 `transform` 与 `opacity`：

| 动词 | 什么时候 | 怎么动 | 时长与缓动 |
| --- | --- | --- | --- |
| 折 | 输入没被采用；拍 2 车道向尺收拢；卡答完收成回执 | 沿竖直方向缩（scaleY），刻痕同时降不透明度；不移动、不飞。按车道成组缩（每条车道的“折掉”“Agent”各一组），不是一道一道缩。车道收拢是整块压到六成、底边不动 | 刻痕 240ms，`cubic-bezier(.55,0,.75,.2)`；车道 600ms，`cubic-bezier(.65,0,.35,1)` |
| 落 | 被采用的输入去到它那件事 | 一颗 5px 的点沿一条弧线落进那件事在尺上的段的中间（横向 `cubic-bezier(.3,.45,.45,1)`、纵向 `cubic-bezier(.55,0,.75,.45)`，在 `@keyframes fl-drop` 里取 11 个样点）；落下即被吸收：压扁、缩没，那一段接收期间加深到 16%；按到达先后依次出发，没有拖尾，演完不留点 | 每颗下落 520–560ms + 吸收约 190ms，相邻错开 20–22ms |
| 让 | 份额重分 | 与点的到达同时：尺上所有段同一条缓动、同起同落地改宽（translateX + scaleX），长的那件随着自己的点落进来变宽；每颗点落在“它到达那一刻”那一段所在的位置（landing.mjs 按同一条曲线算）。尺下的数（主水管 12 → 24 等）一格一格数到新值，每一格在段宽越过那一份时换 | 首屏 1000ms、拍 2 1100ms，`cubic-bezier(.65,0,.35,1)` |
| 定 | 一个数落定 | 先出后进：旧数淡出并下移，之后新数自下 6px 淡入，同一处的两段字不会在任何一帧叠在一起；拍 1 的大数随播放线计数，尺下“涨 / 让”的数随段宽计数，其余不滚动中间值 | 出 140ms，再进 140ms |
| 展 | 一件事要你开口 | 它那一段下面出括线与竖线，卡从竖线下自上而下展开（scaleY 自顶），内容随后淡入；车道同时压到两成，舞台上移，把前两拍车道占的高度让给卡 | 450ms + 150ms，`cubic-bezier(.2,.7,.2,1)` |

- 节拍内动完，节拍外完全静止；同一时刻只有一组动作。朱红总是最后一个出现。
- 不循环：首屏只搭一次（CSS 动画，首绘即开始）；三拍各演一次（状态类给终态，动画与过渡只在“接着上一拍”时挂上）；回到上一拍直接给终态。唯一一直在动的是画廊的轮播和录像，它们在视口外暂停。
- 成组而不是逐个：刻痕放在每条车道按去向分的三个组里，出现靠一个随播放线滑开的窗口（两层反向位移，刻痕本身不动），折靠组的缩放；首屏一共约 90 个动画（原来 479 个），各时刻集中在 `landing.mjs` 的 `TIMING`。
- 可被打断：滚动越过一拍时，那一拍立即跳到终态（去掉过渡类，过渡被取消即到终值），不排队。
- `prefers-reduced-motion: reduce`：首屏与各拍直接给终态，轮播不动（仍可横向拖），录像不自动播放，只显示封面。

## 组件

- **场（第三轮首屏）。** f01…f26 每轮一列（5 个点宽、1 个点的缝），每个点 0.72 个单位见方，按到达先后从下往上；SVG 的 viewBox 是 155 × 47，容器用同一个宽高比，点不会被拉扁。全部点一层墨色、静止时 14% 不透明度；亮着的四档各一层（墨、墨、朱红、朱红）。上方一行等宽小字只写条数（3051），下方一条轴（两周前 / 此刻）。
- **窗。** 1.5px 墨线、`--paper-2` 面，没有阴影；三种形状：圆（手机 156px）、1.7 : 1 的长方形（手机 330 × 194）、比场左右各宽 8px 的整宽（这样复盘的柱正好站在场的列下面）。面积图的格子之间是 1.5px 纸色缝、圆角 5px：等你 `--ver-soft`、要紧 `--ver`（字反白）、Agent 那边 `--agent`、留白虚线框。复盘的柱：每轮排第一的一件 `oklch(0.56 …)`、第二三件 `oklch(0.7 …)`、其余 `--agent`，最后一根（此刻）按等你与否上色。
- **处境按钮。** 三等分一行，上面一条 1px `--rule`，当前那个上面压一条 2px 墨线（随处境平移）；名字 14.5px 粗体，下面一行等宽小字写能看多久；当前的墨色，其余 `--ink-3`。高 48px。
- **第 2 节的图。** 每个来源一行：名字（等宽小字，不写条数）、5px 高的 `--ink-3` 横条，左端一道不随比例缩的 1.5px 短痕（桌面 2px），缩到再小也看得见；“一个软件”那一行墨色加粗，后面跟“← 一个软件”。最后一行“全部加起来”是 12px 高的条，由各行的段首尾拼成，`--ink` 与 `--ink-2` 交替、段间 1px 纸色缝，看得出是一段段拼的。右上一行等宽小字写比例（“满格：一天 500 条”→“满格：一天 1850 条”）。图向右伸到屏幕边（桌面算上居中留白），越过的部分在图里裁掉。
- **少写数字、用白话。** 页面上的数只留讲清论点必需的（首屏每种处境最多一个，第 3 节每行最多一个）；例子用白话的名字（“水管裂了”“猫看病”“儿子病假”），不出现人名、#编号、PR、CI 与瑞典语。对照与原则见 story.md「白话对照」「约束」。

- **刻痕车道。** 一条一道，宽 1.3px、车道高 18px（手机）/ 30px（桌面），墨黑；折掉后为 3px 高的 `--fold` 短桩，贴车道底线。车道底线 `--rule`。
- **尺。** 1px 墨框；每件事一段实色块，段与段之间 2px 纸色缝；空余留白（不填）；64 个刻度画在尺下（每 8 格一个长刻度），刻度永远不动。
- **大数。** Instrument Serif，行高 0.82，旁边一个系统字的单位（份 / 条进来 / 条折掉 / 件要紧）。等你回应的数用朱红，折掉的数用 `--ink-3`。
- **卡（等你回应）。** 1.5px 朱红描边、圆角 14px、`--paper-2` 面；标签行等宽小字朱红；按钮是朱红描边的平按钮，没有阴影，高 44px；脚注右边“演示 · 可以按”。答过以后收成一行回执（与 D 的作答回执同构：圆圈对勾、你选了「…」、小字状态、撤回）：`--rule` 描边、墨黑字。
- **括线与竖线。** 卡和它那一段之间不画斜线（斜的细线在窄屏上几乎看不见），用段下的一道括线和一根竖线，都是 1.5px 朱红；答过后转 `--ink-3`。
- **showcase 卡。** 顶部 1px 墨线；录像框圆角 18px、`--rule` 描边；右上处境标签用等宽小字；“打开原型 ↗”是墨黑实心胶囊按钮。设备只画一条细轮廓线，不画机身与反光（E 折叠屏的录像里自带它自己的机身，那是原型的内容）。
- **gallery 块。** 16:10，圆角 10px，`--rule` 描边；右上可选小标“桌面”“第一轮”。手机 176px 宽、iPad 260px、桌面 300px。
- **导航。** 沿用 VitePress 的导航（高 64px），纸色底、底部一条 `--rule`；左边 Fold 字标（Instrument Serif 28px），右边：一轮整理、六种处境、全部原型 ▾（画册面板）、小册子、文档 ▾（按读者分六组）。

## 文档页（VitePress 默认主题）怎样跟上

只改主题变量、导航和少量全局样式，不重写文档版式（已实现）。

1. `theme/style.css` 的 `:root` 改映射：`--vp-c-bg` → `--paper`，`--vp-c-bg-alt` → `oklch(0.958 0.007 95)`，`--vp-c-text-1/2/3` → `--ink / --ink-2 / --ink-3`，`--vp-c-divider` → `--rule`，`--vp-c-brand-1/2/3` → 墨黑（`--ink` 与它的悬停色 `--ink-2`），`--vp-c-brand-soft` → `oklch(0.9 0.008 95 / .6)`。链接因此是墨黑加下划线，不再是品牌绿。
2. 字体：`--vp-font-family-base` 设为上面的系统中文栈；`--vp-font-family-mono` 设为系统等宽；文档 h1 用 Noto Serif SC 子集（只覆盖站内各篇 h1 用到的字，构建时一起收集），h2 以下保持系统字。
3. 导航：站名换成 Instrument Serif 的 Fold 字标（`.VPNavBarTitle .title` 的字体与字号）；链接改成“一轮整理”“六种处境”“全部原型 ▾”“小册子”“文档 ▾”，其中“全部原型”仍是原来的画册面板（PrototypeMenu），“文档”下拉按读者分组，与入口页文档区同一份清单（`landing.mjs` 的 `DOC_GROUPS`，`config.mts` 读它）。主题从 `vitepress/theme-without-fonts` 继承，去掉自带的 Inter。
4. 深色：`.dark` 下用墨底纸字（见上），去掉现在的绿色调深底。
5. 文档里的配图、Mermaid、公式样式不动；代码块底色跟 `--vp-c-bg-alt`。
6. 原型说明页、小册子、原型本身都不改。
