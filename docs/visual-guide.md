## 图注里需要区分的内容

- 一张图服务一个位置的具体论述。同一主题在不同文档里分别解释产品体验、契约边界或数学关系，配图随视角重画；需要关联时链接相应段落。
- 同一处的图片可以与文字、公式或 Mermaid 冗余，方便人和 LLM 阅读；关键关系应有可直接读取的表达，并与图片保持一致。
- 05 用抽象关系说明先理解要点、再按需深入，不预设具体应用形态。08 在 US-03 的具体场景里展示满额取舍，其中的数字不能自动变成重要性算法。
- 收到消息、Agent 已读、展示调整与外部行动完成是不同事实。
- 输入记录说明收到了什么；状态记录说明接受了哪些变化。不能从有损状态恢复全部原始输入。
- 版本检查、字段、技术栈等候选方案没有因为画成图就变成已实现能力。
- 维护图文时要同时核对标题、箭头、数值与正文；不能仅以图片生成完成作为正确性依据。
