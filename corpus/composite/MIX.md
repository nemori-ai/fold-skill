# composite：一个化名人物的两周

状态：由 `scripts/compose_corpus.py build` 生成 `frames.json` 与 [ids.json](ids.json)；噪音画像见 [NOISE.md](NOISE.md)，弱标注见 [LABELS.md](LABELS.md)。人物是化名拼成的，各流来自不同真实的人的公开数据；文本都是真实原文，只做了规则替换，没有用模型生成或改写。家庭往来流尚未启用，原因见[家庭往来](#家庭往来为什么还没有)。

## 改写规则

所有替换都来自一张只存本机的化名表（`.local/composite/mapping.json`，含随机盐，不入库），同一个真实名字在所有流里换成同一个化名。

- **项目与组织**：项目名在标识符里也替换并保持大小写（如 `libskarv`、`SKARVOPT_URL`），相关工具、公司、仓库、邮件列表与域名一并替换；第三方库与平台（OpenSSL、c-ares、GitHub、Mastodon 实例）保留。
- **账号**：GitHub、Mastodon、论坛与问答站的账号换成生成的化名（如 `windy-drift`）；`@提及`、引用块、链接路径、查询参数与个人实例的主机名一起换；平台机器人（`github-actions`、Copilot 评审）保留。
- **人名**：作者栏的全名换成化名全名；正文里出现的常见人名（系统人名表中、又不是普通英文词的）与其后的姓一起换；名与姓允许多对一。
- **问答的提问者**：34 位提问者只在各自的问题下换成本人（作者栏与 `@` 提及）；他们在别的问题下出现时，和其他人一样用普通化名。
- **编号**：项目仓库的 issue/PR 编号整体减 9000（保持先后与互相引用；`仓库#编号`、`refs/pull/编号/head`、百分号编码的链接和正文里裸写的已知编号一并平移），CVE、HackerOne 报告、CI 运行、Mastodon 帖子、论坛话题（含引用头里的 `topic:`）与问答帖子的编号换成等长的稳定化名，链接里评论与评审的锚点和对应输入的 ID 用同一映射，提交哈希按前 7 位映射以保证长短缩写一致。
- **邮件地址**：本人的地址换成 `jonas@berglund.example`；看起来属于个人的地址换成化名，营销与客服类地址保留。
- **营销邮件**：订单、注册、出票等交易类邮件不用（含收件人姓名与住址）；称呼与“FOR 收件人”换成本人；8 位以上数字、发件地址与链接里的跟踪串换成等长化名；正文里的日期与年份随整周平移。
- **时间**：工作、社区、newsletter 与天气都是同一窗口的真实时间。生活问答里斯德哥尔摩 0–7 点提出的问题，整条线程平移 −6 小时，按北美东部的钟面时间对齐。营销邮件从 2001-05-28（周一）平移 9198 天到 2026-08-03（周一），星期几与一天中的时段不变。
- 每条输入带 `stream` 与 `origin`；`origin` 是原始记录 ID 的加盐摘要，持有本机盐可以逐条核对，公开的清单不能反查原始记录。

这是化名，不是匿名：正文是真实原文，逐字搜索仍可能找回出处。改写的目的是不在演示与评测数据里直接展示真实的人。

## 修订

第一版发出后又修补了几处改写遗漏，输入条数、帧与流的划分不变：

- 4 条博客评论的 ID 与所在线程改为化名编号（原来保留了原始编号）。
- 论坛引用头里的话题号、链接里评论与评审的锚点、正文里裸写或百分号编码的项目编号，此前保留原值，现在化名。
- 问答的提问者此前在所有问题下都被换成本人，导致 21 条别人的回答与评论署名成本人；现在只在各自的问题下替换。
- 营销邮件发件地址与链接里的跟踪串换成化名。

## 家庭往来为什么还没有

原计划从 Enron 语料挑选私人往来（家人、孩子、医生、账单、朋友约饭），统一成一个家庭并平移日期。挑选时用脚本列出私人邮件正文，被权限系统以处理个人敏感信息为由拦下；按规则没有绕过，也没有改用别的方式读取或盲改写这些邮件。是否启用由用户决定。在此之前，生活流改用作者本来就面向公众发布的问答（Stack Exchange），Enron 只取商业群发，不含人与人之间的私人往来。

## 接缝

拼接人物必然有对不上的地方，评测时应当知道它们来自拼接而不是 Agent 的误读：

- 生活问答来自 34 位不同的人：有人说住公寓、有人有车道和棚屋，有人提到住在法国，房屋问题多按北美的电气与建材习惯。
- 营销邮件的正文是 2001 年的：CD 商店、父亲节礼物、按美元计价的航线。
- 论坛上的“本人”与工作中的本人是不同的真实的人，写作风格不同。
- 天气提醒是用当天的观测值生成的模板，不是当时发布的预报；这两周斯德哥尔摩几乎没有降水。
- 常见人名规则会误伤专有名词（例如某个奖项名里的名字被换掉）。

## 重建

需要 curl-bagder 的 `raw/` 已抓好、Enron 压缩包已缓存，并持有本机化名表：

```sh
.venv/bin/python scripts/fetch_corpus.py composite        # 论坛、问答、newsletter、天气
.venv/bin/python scripts/compose_corpus.py build          # frames.json；与入库的 ids.json 对照
.venv/bin/python scripts/compose_corpus.py labels         # labels.json：各流的弱标注与跨流的事
.venv/bin/python scripts/compose_corpus.py noise          # noise.json：与 curl-bagder、手写情境并排
.venv/bin/python scripts/compose_corpus.py audit --sample 30   # 抽样核对，并扫描残留的真实名字
```

没有化名表时，第一次运行会生成一张新的（新的盐、新的化名），各流的挑选需要重新填写，ID 会与入库的清单不同。
